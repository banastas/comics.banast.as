# Full-site QA: October 17, 2026

Status: fixes implemented locally and verified in Cloudflare's local Pages runtime. Not committed or deployed.

## Bugs fixed

| Priority | Finding | Resolution |
| --- | --- | --- |
| P1 | Sorting by Current Value or Purchase Price was scrambled: the comparator treated missing values as equal to everything, so Star Wars #70 ($450) did not sort first. | `sortCollection` puts unrecorded values last in both directions and breaks ties by series, issue and ID. Regression tests cover both fields against the real data. |
| P1 | CI failed on every data sync since Sept 22: tests hard-coded 853 comics, and the tracked sitemap went stale because the sync tool doesn't regenerate it. | Tests derive counts from the data. `public/sitemap.xml` is now untracked derived output (the build always regenerates it) and the CI diff step is gone. |
| P2 | The sync tool rewrites every `updatedAt` (and ~370 `createdAt`), so "Added to Collection" dates and every sitemap `lastmod` were wrong. | The sitemap omits `lastmod`; comic pages no longer show internal record dates. The source app's export still needs fixing (see below). |
| P2 | Direct visits to series, box, artist and tag pages briefly rendered "Page Not Found" with `noindex` before the data loaded; analytics sent two page views per visit and the previous page's title on navigation. | Routes resolve only after data loads. Page views are sent once per URL from the SEO component, after the title is set. |
| P2 | Missing purchase prices appeared as $0 or tiny unlabeled sums (related issues, "Top Series by Count"). | Related issues show cards with values; series lists show labeled current value; unknown prices read "Not recorded" or "—". |
| P2 | Comic cards and every other navigation target were `role="button"` divs, with no links to open in a new tab or crawl. | All navigation uses real `<a href>` links that keep plain clicks in the app. |
| P2 | Grid thumbnails loaded ~400 KB originals with a per-card IntersectionObserver spinner. | Native lazy loading; optional resized `srcset` through Cloudflare Image Transformations (`VITE_COVER_RESIZE=cloudflare`). |
| P3 | Series containing issue #0 printed a stray "0". | Fixed, with a test. |
| P3 | The collection page number wasn't in the URL; URLs carried every default parameter. | `?page=N` is kept; default view, sort, order and tab are omitted. |
| P3 | Static and hydrated metadata disagreed (canonical for `/collection`, tag/box/variant titles, robots directive). | Client titles, descriptions, canonicals and robots match the generated pages. `/collection` canonicalizes to `/`. |
| P3 | Invalid structured data (`offers` on a collection that isn't for sale, `numberOfItems`/`additionalProperty` on the wrong types, issue names without numbers). | Static and client JSON-LD rebuilt to equivalent, valid shapes with a parity test. |
| P3 | Currency like "$363.3", contrast failures on blue chips and page buttons, heading order, no skip link, misleading timeline gaps, contradictory ROI figures, "+$0.00" with an up arrow. | Fixed. |
| P3 | API: no cache or security headers, no pagination, HEAD returned HTML, a 10.0 grade would land in a "10–11" bucket. | Fixed with tests; `limit`/`offset` are optional and backward compatible. |
| P3 | The CSP gave no script protection. | Enforcing CSP with hashed inline scripts; a test fails if `index.html` changes without updating the hashes. |
| P3 | A failed lazy chunk (e.g. after a deploy) stuck until reload. | Retry, then one guarded reload; route error boundaries reset on navigation. |

## Design and UX changes

- One header on every page with search (searching from any page lands on the results), Collection / Statistics / Boxes tabs, and a footer.
- Collection: a heading with a filter-aware summary replaces six stat cards; type links and tag chips scroll on one row on phones. The first cover moved from ~1,150px to ~390px down the page at 375px wide. Tag counts follow the active search.
- Detail pages show comics first, with highlights below. Returns are hidden when fewer than half the comics have recorded costs.
- Comic pages: "Series #N" title, grade badge, cover zoom, previous/next issue, linked artist/box/tags, related covers, and no internal dates.
- Cards distinguish variants by cover artist and show a "Raw 9.4" / "Slab 9.4" grade badge instead of a star; placeholder covers render a designed "cover coming soon" tile.
- Statistics: subtler highlight cards, multiples for very large gains ("199× cost"), visitor-facing copy, "Record completeness" in place of "Collection Health".
